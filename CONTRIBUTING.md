# Contributing

Submit a range as a GeoJSON file under `data/ranges/<taxonKey>/`. The `github` property is optional. When set, it must be your GitHub login, and CI fails when it differs from the PR author. Without GitHub, sign in on the site (ORCID, iNaturalist, GitHub or an email link) when the relay is enabled and press Submit: the relay bot opens the PR with a `submitter` property naming who signed in. Only the relay bot may set `submitter`, and it never changes afterwards; an email sign-in is unverified and a maintainer merge counts as the vouch. Otherwise download your range and send it to a maintainer. Your ORCID or iNaturalist id carries your expertise record either way.

Merge policy: pull requests are squash-merged only. Scoring takes the credit owner and the prospective cutoff from the first-parent commit that added the file. On a squash merge GitHub sets the author email (`<id>+<login>@users.noreply.github.com`) and the commit date, so neither can be chosen by the contributor. A commit without a noreply email is credited by its git author name and marked `identity: "unverified"`, and its external expertise is never marked verified. Repository settings must disable merge commits and rebase merging.
